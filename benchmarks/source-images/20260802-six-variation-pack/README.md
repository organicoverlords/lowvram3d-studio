# Six-variation benchmark source pack

These six files are byte-for-byte copies of the immediate image files in
`C:\Users\Lauri\Downloads\benchmarkpics` on 2026-08-02. The stable names are
assigned by visual identity and are recorded in `manifest.json`.

This folder is the single immutable Git source pack for the first six-asset
textured-baseline milestone. The original files were not renamed, moved,
recompressed, edited, or deleted.

The six routes are static or non-animated baseline routes only. Rigging,
animation, advanced retopology, LOD refinement, and advanced PBR work are out
of scope for this milestone.
